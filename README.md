# DUO — MATE × HomeChef (single-page website)
Open `index.html` to preview. No build step.

## 1. Add your APKs
Put the files here (exact names): `assets/apk/MATE.apk` and `assets/apk/HomeChef.apk`.
Tip: APKs over 100 MB can't live in a normal repo. Upload them to GitHub Releases and set each download button's `href` to the release asset URL.

## 2. Real screenshots (optional)
The phones are CSS mockups. To use real screenshots, put PNGs in `assets/screens/` and replace a phone div with
`<img class="phone" src="assets/screens/mate1.png" alt="MATE dashboard">`.

## 3. GitHub link
In `index.html`, replace `YOUR-USERNAME/YOUR-REPO` in the footer.

## 4. Deploy on GitHub Pages
Push all files to a repo > Settings > Pages > Deploy from branch `main` / root.
